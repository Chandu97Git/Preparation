🔹 Class:
-------------
👉 "A class in C# is a blueprint used to create objects. It contains properties and methods that define the data and behavior of an object."

🔹 Simple Definition
A class is a user-defined data type that groups:
Variables (fields / properties)
Methods (functions)
🔹 Key Points (Interview Important)
Class is a reference type
It does not occupy memory until object is created
Supports OOP concepts:
Encapsulation
Inheritance
Polymorphism
Abstraction

🔹 Real-Time Example
Think of a Car 🚗
Class → Car (blueprint)
Properties → Color, Model, Speed
Methods → Start(), Stop(), Drive()

🔹 What is a Method?
👉 "A method is a named block of code that performs a task. It can either return a value (function) or not return anything (void method)."

🔹 Types of Methods

1️⃣ Value Returning Method (Function)
👉 These methods return a value

int Add(int a, int b)
{
    return a + b;
}
✔️ Usage:
int result = Add(5, 3);
Console.WriteLine(result); // 8

2️⃣ Non-Value Returning Method (Subroutine)
👉 These methods do not return anything
👉 They use void

{
    Console.WriteLine("Hello Chandu");
}
✔️ Usage:
ShowMessage();

🔹 1. Method Syntax (Clean Version)

}

👉 Example:

✅ 2. Return Type (void or type)
void → no return value
int, string, etc. → returns value

👉 Examples:

✔️ Important:

✅ 4. Parameters (Optional)

Used to pass data into method.

🔹 Consuming a class from other classes?
A class can be consumed in another class mainly in two ways: by creating an instance (object) to access its members, and by using inheritance where a derived class can directly access base class members. Additionally, static members can be accessed directly using the class name.

🔹 1. What are Parameters?
Parameters in C# are used to pass values to methods. They are of three types: input parameters (default), output parameters using out, and input-output parameters using ref. Additionally, params allows multiple values, and default parameters make arguments optional
🔹 3. Types of Parameters
1️⃣ Input Parameters (Default)

👉 These send values into method

{
    Console.WriteLine(a);
}

✔️ By default → all parameters are input

2️⃣ Output Parameters (out)

👉 Used to return values from method

{
    sum = a + b;
}

Calling:

✔️ Must assign value inside method
✔️ Used for multiple outputs

3️⃣ InOut Parameters (ref)

👉 Used to send value + modify same variable

{
    x = x * x;
}

Calling:

Square(ref a);

✔️ Input + Output in same variable
1️⃣ Difference: ref vs out
ref → Pass variable by reference, must be initialized before passing.
out → Pass variable by reference, no need to initialize before passing, but must assign in method.
using System;

class Program
{
    static void RefExample(ref int a)
    {
        a += 10;
    }

    static void OutExample(out int b)
    {
        b = 20; // Must assign
    }

    static void Main()
    {
        int x = 5;
        RefExample(ref x);
        Console.WriteLine("Ref: " + x); // 15

        int y;
        OutExample(out y);
        Console.WriteLine("Out: " + y); // 20
    }
}

🔹 1. Variable, Instance, and Reference of a Class
"A variable holds a reference, an instance is the actual object in heap memory, and a reference is another variable pointing to the same object. Multiple references can point to the same instance, sharing the same memory."
1️⃣ Variable of a Class
A variable of a class is just a placeholder, not initialized, no memory allocated yet.
You cannot access members through it until it’s assigned an object.
First f; // f is a variable of class First
// Console.WriteLine(f.x); // ❌ Invalid, not initialized
2️⃣ Instance of a Class
An instance is created using the new keyword.
Memory is allocated in heap for its members.
Through this instance, we can access class members.
First f = new First(); // Instance creation
Console.WriteLine(f.x); // ✅ Valid
Multiple instances: each has its own memory.
First f1 = new First();
First f2 = new First();
f1.x = 200;
f2.x = 300;
Console.WriteLine(f1.x); // 200
Console.WriteLine(f2.x); // 300
3️⃣ Reference of a Class
A reference points to an existing instance.
It does not create new memory — it uses the same memory as the instance.
First f1 = new First(); // Instance
First f2 = f1;          // Reference to f1
f2.x = 300;
Console.WriteLine(f1.x); // 300 (same memory)
Changing f1 or f2 affects the same object.
Assigning null to one reference does not affect the other.
f1 = null;
Console.WriteLine(f2.x); // ✅ Still works
// Console.WriteLine(f1.x); // ❌ Runtime error
🔹 4. De-referencing an Instance
Assign null to an instance → you lose access to that object through this variable.
Memory is not immediately freed → Garbage Collector will clean it up later.
f = null; // marks object as unused





OOPS Concepts in C#
-------------------
🔷 Encapsulation: 
Encapsulation means hiding the internal details of an object and exposing only what’s necessary.
We can achieve this using access modifiers like private, public, protected, and internal, along with properties and methods.
For Ex:
-------
using System;

public class Student
{
    private int fee;

    public void SetFee(int amount)
    {
        if (amount > 0)
            fee = amount;
    }

    public int GetFee()
    {
        return fee;
    }
}

class Program
{
    static void Main(string[] args)
    {
        Student student = new Student();   // object creation

        student.SetFee(5000);              // set value

        int result = student.GetFee();     // get value

        Console.WriteLine("Fee: " + result);
    }
}
I have created a Student class with a private variable fee, which cannot be accessed directly from outside the class. This ensures data protection.
To interact with this private data, I have provided two public methods:

SetFee(int amount) → used to assign value
GetFee() → used to retrieve value

In the SetFee method, I added a validation condition to ensure that only positive values are assigned to the fee. This helps in maintaining data integrity.
In the Main method, which is the entry point of the program, I created an object of the Student class. Then I called the SetFee method to assign a value and used the GetFee method to retrieve it. Finally, I printed the result using Console.WriteLine.
This approach ensures controlled access to data and prevents invalid values from being assigned.

🔷 Inheritance:
Inheritance allows a class (child/derived) to inherit fields and methods from another class (parent/base), promoting code reuse and hierarchical relationships.

using System;
public class Person
{
    public string Name;

    public void DisplayName()
    {
        Console.WriteLine("Name: " + Name);
    }
}

public class Student : Person   // Inheritance
{
    public int Fee;

    public void DisplayFee()
    {
        Console.WriteLine("Fee: " + Fee);
    }
}

class Program
{
    static void Main(string[] args)
    {
        Student student = new Student();

        student.Name = "Chandu";   // inherited
        student.Fee = 5000;

        student.DisplayName();     // parent method
        student.DisplayFee();      // child method
    }
}
Inheritance is a concept where a child class inherits properties and methods from a parent class. In this example, Student is the child class and Person is the parent class.
The Student class inherits the Name property and DisplayName() method from the Person class using the : symbol. It also has its own property Fee and method DisplayFee().
In the Main method, I created an object of the Student class and accessed both inherited and its own members. This demonstrates how inheritance helps in reusing code and reducing duplication.

Types of Inheritance:
Single Inheritance : One derived class inherits from one base class  
Multilevel Inheritance : A derived class inherits from another derived class
Hierarchical Inheritance : Multiple derived classes inherit from a single base class
Multiple Inheritance : One class inherits from multiple base classes. C# does NOT support multiple inheritance with classes, But you can achieve it using interfaces
Hybrid Inheritance : Combination of two or more inheritance types

🔷 Polymorphism:
Polymorphism means one method can have multiple forms. It is of two types: compile-time and runtime polymorphism. Compile-time polymorphism is achieved using method overloading, where the same method name has different parameters. Runtime polymorphism is achieved using method overriding, where a child class provides a different implementation of a parent class method using virtual and override keywords.
using System;

Method Overload
using System;

class Calculator
{
    // Method 1
    public int Add(int a, int b)
    {
        return a + b;
    }

    // Method 2 (different number of parameters)
    public int Add(int a, int b, int c)
    {
        return a + b + c;
    }

    // Method 3 (different type)
    public double Add(double a, double b)
    {
        return a + b;
    }
}

class Program
{
    static void Main()
    {
        Calculator obj = new Calculator();

        Console.WriteLine(obj.Add(2, 3));        // 5
        Console.WriteLine(obj.Add(2, 3, 4));     // 9
        Console.WriteLine(obj.Add(2.5, 3.5));    // 6.0
    }
}

Method Override
public class Animal
{
    public virtual void Sound()
    {
        Console.WriteLine("Animal makes sound");
    }
}

public class Dog : Animal
{
    public override void Sound()
    {
        Console.WriteLine("Dog barks");
    }
}

class Program
{
    static void Main()
    {
        Animal obj = new Dog();  // parent reference, child object
        obj.Sound();
    }
}
🔷 Abstraction
Abstraction is used to hide implementation details and expose only necessary functionality. It can be achieved using abstract classes and interfaces. In an abstract class, we can have both abstract and non-abstract methods, whereas interfaces contain only method declarations. This helps in reducing complexity and improving code maintainability.
using System;
🔥 Example Using Abstract Class

public abstract class Vehicle
{
    public abstract void Start(); // no implementation

    public void Stop()
    {
        Console.WriteLine("Vehicle stopped");
    }
}

public class Car : Vehicle
{
    public override void Start()
    {
        Console.WriteLine("Car starts with key");
    }
}

class Program
{
    static void Main()
    {
        Vehicle v = new Car();
        v.Start();
        v.Stop();
    }
}
🔥 Example Using Interface
interface IPayment
{
    void Pay();
}

class CardPayment : IPayment
{
    public void Pay()
    {
        Console.WriteLine("Payment by Card");
    }
}



2️⃣ Difference: var vs dynamic
var → Compiler determines type at compile-time, strongly typed. If the variable does not initialized it throw an error.
dynamic → Type is determined at runtime, no compile-time checking. If the variable does not initialized it will not throw an error.

var a = 10;        // int, compiler knows
dynamic b = 10;    // type is determined at runtime
b = "Hello";       // valid

3️⃣ What is using statement?
Automatically disposes objects that implement IDisposable when scope ends.
using (var con = new SqlConnection(connectionString))
{
    con.Open();
    // do database work
} // connection disposed automatically

🔷 Collections, Generics and List
Collections are used to store multiple objects. Generics provide type safety, and List<T> is a commonly used generic collection for dynamic data storage.
