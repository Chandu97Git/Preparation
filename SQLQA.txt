1. What is a JOIN?
A JOIN is used to combine data from two or more tables based on a related column. For example, if I have Employees and Departments tables, I can join them using DepartmentId to retrieve employee and department information together.
Common joins are INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN.

2. Explain INNER JOIN, LEFT JOIN, RIGHT JOIN and FULL OUTER JOIN.
INNER JOIN
Returns only the records that have matching values in both tables.

SELECT e.EmployeeName, d.DepartmentName
FROM Employees e
INNER JOIN Departments d
    ON e.DepartmentId = d.DepartmentId;

LEFT JOIN
Returns all records from the left table and matching records from the right table. If there is no match, the right-side columns return NULL.

RIGHT JOIN
Returns all records from the right table and matching records from the left table.

FULL OUTER JOIN
Returns matching records as well as unmatched records from both tables.

3. INNER JOIN vs LEFT JOIN
INNER JOIN returns only matching records, whereas LEFT JOIN returns all records from the left table, including those that don't have a match in the right table.

4. What is a SELF JOIN?
A self join is when a table is joined with itself. It is commonly used for hierarchical relationships, such as an employee and their manager when both are stored in the same Employees table.

SELECT e.EmployeeName,
       m.EmployeeName AS ManagerName
FROM Employees e
LEFT JOIN Employees m
    ON e.ManagerId = m.EmployeeId;

5. Find employees who don't have a department.
SELECT e.*
FROM Employees e
LEFT JOIN Departments d
    ON e.DepartmentId = d.DepartmentId
WHERE d.DepartmentId IS NULL;

I use a LEFT JOIN and filter where the department key is NULL. This gives employees for whom no matching department exists.

6. Find departments that don't have employees.
SELECT d.*
FROM Departments d
LEFT JOIN Employees e
    ON d.DepartmentId = e.DepartmentId
WHERE e.EmployeeId IS NULL;

7. What is GROUP BY?
GROUP BY groups rows having the same values so that aggregate functions such as COUNT, SUM, AVG, MIN, and MAX can be applied to each group.
SELECT DepartmentId,
       COUNT(*) AS EmployeeCount
FROM Employees
GROUP BY DepartmentId;

8. WHERE vs HAVING
WHERE filters individual rows before grouping, whereas HAVING filters groups after aggregation.

SELECT DepartmentId,
       COUNT(*) AS EmployeeCount
FROM Employees
WHERE Salary > 30000
GROUP BY DepartmentId
HAVING COUNT(*) > 5;

9. Find the number of employees in each department.
SELECT DepartmentId,
       COUNT(*) AS EmployeeCount
FROM Employees
GROUP BY DepartmentId;

10. Find departments having more than 5 employees.
SELECT DepartmentId,
       COUNT(*) AS EmployeeCount
FROM Employees
GROUP BY DepartmentId
HAVING COUNT(*) > 5;

11. Find the highest salary in each department.
SELECT DepartmentId,
       MAX(Salary) AS HighestSalary
FROM Employees
GROUP BY DepartmentId;

12. Find the average salary by department.
SELECT DepartmentId,
       AVG(Salary) AS AverageSalary
FROM Employees
GROUP BY DepartmentId;

13. What is a subquery?
A subquery is a query written inside another SQL query. It is useful when the result of one query is required by another query.


17. What is EXISTS?

EXISTS checks whether a subquery returns at least one row. It is useful when I only need to know whether related data exists, rather than retrieving the related data itself.

SELECT *
FROM Employees e
WHERE EXISTS
(
    SELECT 1
    FROM Departments d
    WHERE d.DepartmentId = e.DepartmentId
);

18. Subquery vs JOIN
A JOIN combines rows from tables, whereas a subquery is a query nested inside another query. I choose between them based on readability, required result, and execution plan. I wouldn't assume one is always faster than the other.

19. What is a CTE?
CTE stands for Common Table Expression. It is a temporary named result set that exists only for the duration of a single SQL statement. I mainly use CTEs to improve query readability, break complex logic into steps, and handle recursive queries.

WITH EmployeeData AS
(
    SELECT *
    FROM Employees
    WHERE Salary > 50000
)
SELECT *
FROM EmployeeData;

20. CTE vs Temporary Table
A CTE is statement-scoped and is mainly useful for structuring a query. A temporary table is stored in tempdb for its scope, can be indexed, and can be useful when I need to reuse intermediate results across multiple statements.

24. ROW_NUMBER vs RANK vs DENSE_RANK
ROW_NUMBER ===> Gives every row a unique number.
RANK ==> Same values get the same rank, but gaps are created.
DENSE_RANK ==> Same values get the same rank without gaps.

✅ What is SQL?
SQL is a standard language used to interact with relational databases. It helps in storing, retrieving, updating, and managing data efficiently
SQL is used to communicate with databases to perform operations like:Insert data, Retrieve data, Update data, Delete data

✅ What is a Relational Database?
A Relational Database is a type of database that stores data in the form of tables (rows and columns) and maintains relationships between those tables using keys.

Components of a SQL System
-------------------------
Database : A structured collection of data stored in tables with rows and columns.
Tables   : Store data and apply rules to keep it accurate and consistent.
Indexes  : Help the database find data faster without scanning the whole table.
Views    : Virtual tables created from SELECT queries for easy access to data.
Stored Procedures : Pre-saved SQL code that runs tasks and improves performance and security.
Transactions   : Group of SQL actions that either all succeed or all fail to keep data safe.
Security & Permissions: Control who can view, change or manage database data.
Joins: Combine data from different tables based on relationships.

🔹 What Can SQL Do?
Create databases and tables
Insert data (INSERT)
Fetch data (SELECT)
Update data (UPDATE)
Delete data (DELETE)
Control access (GRANT, REVOKE)

🔹 2. What are the main types of SQL statements?
SQL statements are classified into DDL, DML, DQL, DCL, and TCL. They are used to define structure, manipulate data, retrieve data, control access, and manage transactions respectively

✅ Main Types of SQL Statements
SQL statements are mainly divided into 5 types:

🔹 1. DDL (Data Definition Language)
--------------------------------------
👉 Used to define or modify database structure
Commands:
CREATE → Create table/database
ALTER → Modify table
DROP → Delete table
TRUNCATE → Remove all data

Example:
--------
CREATE TABLE Employees (id INT, name VARCHAR(50));

ALTER TABLE Employee ADD Email VARCHAR(100);

ALTER TABLE Employee ALTER COLUMN Email VARCHAR(200);

ALTER TABLE Employee DROP COLUMN Age;

🔹 2. DML (Data Manipulation Language)
----------------------------------------
👉 Used to manipulate data inside tables
Commands:
INSERT → Add data
UPDATE → Modify data
DELETE → Remove data
Example:
INSERT INTO Employees VALUES (1, 'Chandu');

🔹 3. DQL (Data Query Language)
👉 Used to retrieve data
Command:
SELECT
Example:
SELECT * FROM Employees;

🔹 4. DCL (Data Control Language)
👉 Used to control access/permissions
Commands:
GRANT → Give access
REVOKE → Remove access

🔹 5. TCL (Transaction Control Language)
👉 Used to manage transactions
Commands:
COMMIT → Save changes
ROLLBACK → Undo changes
SAVEPOINT → Set checkpoint

✅ Execution Order of a SQL Query
This is a very common interview question. Although we write the query in one order, SQL Server processes it in a different order.

| Written Order | Execution Order              |
| ------------- | ---------------------------- |
| SELECT        | 4                            |
| FROM          | 1                            |
| WHERE         | 2                            |
| ORDER BY      | 5                            |
| TOP           | 6 (after sorting the result) |
| DISTINCT      | 3                            |

SELECT DISTINCT TOP 2 Name
FROM Employee
WHERE Salary > 35000
ORDER BY Name;

SQL Server logically processes it as:
-------------------------------------------
Read data from Employee (FROM)
Filter rows with Salary > 35000 (WHERE)
Remove duplicate names (DISTINCT)
Select the Name column (SELECT)
Sort names alphabetically (ORDER BY)
Return only the first 2 rows (TOP)

✅ What is a Primary Key?
A Primary Key is a field that uniquely identifies each row in a table and cannot contain NULL or duplicate values.
🔹 Key Characteristics
✔ Must be unique
✔ Cannot be NULL
✔ Only one primary key per table
✔ Can be single column or composite (multiple columns)
CREATE TABLE Employees (
    id INT PRIMARY KEY,
    name VARCHAR(50)
);
CREATE TABLE StudentCourses (
    student_id INT,
    course_id INT,
    PRIMARY KEY (student_id, course_id)
);
✅ 2. Composite Primary Key (Important 🔥)
A primary key can be a single column or a combination of columns (composite key). Composite keys are used when one column is not sufficient to uniquely identify a record.
👉 When one column is NOT enough, we combine multiple columns to uniquely identify a record.

✅ What is a Foreign Key?
“A foreign key is a column in one table that references the primary key of another table and is used to maintain relationships and data integrity.”
| id | dept_name |
| -- | --------- |
| 10 | HR        |
| 20 | IT        |
| id | name   | dept_id |
| -- | ------ | ------- |
| 1  | Chandu | 10      |
| 2  | Ravi   | 20      |

CREATE TABLE Employees (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    dept_id INT,
    FOREIGN KEY (dept_id) REFERENCES Departments(id)
);
✅ Why Foreign Key is Important?

✔ Maintains data integrity
✔ Prevents invalid data (e.g., dept_id that doesn't exist)
✔ Creates relationships between tables

✅ What is Data Integrity?
“Data integrity ensures that data in the database is accurate, consistent, and reliable, and it is maintained using constraints like primary key and foreign key.”

✅ What is a Unique Key?
“A Unique Key ensures that all values in a column are unique. Unlike a primary key, it can allow NULL values and a table can have multiple unique keys.”
CREATE TABLE Employees (
    id INT PRIMARY KEY,
    email VARCHAR(100) UNIQUE
);
🔹 Key Characteristics
✔ No duplicate values
✔ Can allow NULL (usually one NULL in SQL Server)
✔ A table can have multiple Unique Keys
✔ Used for fields like:
Email
Phone number
Aadhaar / PAN
Aadhaar / PAN

✅ What is a JOIN in SQL?
“A JOIN is used to combine data from multiple tables based on a related column, usually a primary key and foreign key relationship.”
SELECT e.name, d.dept_name
FROM Employees e
INNER JOIN Departments d 
ON e.dept_id = d.id;

🔥 Types of JOINs
✅ 1. INNER JOIN 👉 Returns only matching records
✔ Common data only

SELECT e.name, d.dept_name
FROM Employees e
INNER JOIN Departments d 
ON e.dept_id = d.id;

✅ 2. LEFT JOIN (LEFT OUTER JOIN)
👉 Returns:
All records from left table
Matching from right
Non-matching → NULL

SELECT e.name, d.dept_name
FROM Employees e
LEFT JOIN Departments d 
ON e.dept_id = d.id;

✅ 3. RIGHT JOIN
👉 RIGHT JOIN returns:
All records from the right table
Matching records from the left table
Non-matching from left → NULL

SELECT e.name, d.dept_name
FROM Employees e
RIGHT JOIN Departments d
ON e.dept_id = d.id;

✅ 4. FULL JOIN
👉 Returns:
All records from both tables
Non-matching → NULL
👉 Question:
Get all employees and departments, including unmatched records.

SELECT e.name, d.dept_name
FROM Employees e
FULL JOIN Departments d 
ON e.dept_id = d.id;

✅ 7. Self JOIN (Tricky 🔥)
👉 Question:
Find employees and their managers.
SELECT e.name AS Employee, m.name AS Manager
FROM Employees e
LEFT JOIN Employees m 
ON e.manager_id = m.id;

✅ What is a CROSS JOIN?
A CROSS JOIN returns the Cartesian product of two tables.A CROSS JOIN returns all possible combinations of rows between two tables.
SELECT e.name, d.dept_name
FROM Employees e
CROSS JOIN Departments d;

✅ Difference Between WHERE and HAVING
WHERE filters rows before grouping, while HAVING filters grouped data after applying aggregate functions.
🔹 WHERE Example
SELECT * 
FROM Employees
WHERE salary > 50000;

🔹 HAVING Example
SELECT dept_id, SUM(salary)
FROM Employees
GROUP BY dept_id
HAVING SUM(salary) > 100000;

Subquery vs JOIN?
-----------------
A JOIN combines tables directly. A subquery is a nested query used to produce a value/set or test existence.

CTE — Common Table Expression ⭐⭐⭐
A CTE is a temporary named result set that exists only for the duration of a single statement.
