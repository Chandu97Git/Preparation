🔹 What is WebApplicationBuilder and WebApplication?
A) WebApplicationBuilder is used to configure services and settings, while WebApplication is the built application used to define middleware and handle HTTP requests.

🔷 What is Middleware in ASP.NET Core?
👉 Middleware is a component that handles HTTP requests and responses in the ASP.NET Core pipeline.
Every request passes through a series of middleware components
Each middleware can:
Process the request
Modify the response
Pass control to the next middleware
Or stop the pipeline

🔷 Types of Middleware
1. Built-in Middleware

Common ones you should mention in interviews:
UseRouting() → Matches URL to endpoint
UseAuthentication() → Validates user identity
UseAuthorization() → Checks permissions
UseStaticFiles() → Serves images, CSS, JS
UseExceptionHandler() → Handles global errors

2. Custom Middleware

👉 You can create your own middleware to handle logic like:

Logging
Exception handling
Request validation
Performance tracking
🔷 Important Middleware Methods
1. Use()
Calls next middleware
Most common
🔹 2. Run()
Terminal middleware (stops pipeline)
🔹 3. Map()
Branches pipeline based on URL

🔷 What is Rate Limiting?
👉
Rate limiting restricts how many requests a client can send to an API within a specific time period.

🔷 1. What is Middleware?
Middleware is a component that is part of the HTTP request pipeline and is responsible for handling requests and responses, either by processing them or passing them to the next middleware.

🔷 2. Difference between Use, Run, Map
Use continues the pipeline, Run terminates the pipeline, and Map branches the pipeline based on request path.

🔷 3. What is Short-Circuiting?
Short-circuiting means stopping the request pipeline early without passing control to the next middleware.

🔷 4. Why Middleware Order Matters?
Middleware order matters because each middleware depends on the previous one, and incorrect order can lead to failures like authentication or routing not working properly.
🔷 Middleware Execution Order (Very Important)

👉 Order matters a LOT

Correct order example:

app.UseExceptionHandler("/error");
app.UseStaticFiles();
app.UseRouting();
app.UseAuthentication();
app.UseAuthorization();
app.MapControllers();

🔷 5. Middleware vs Filters
Middleware works at the application level for all requests, while filters work within the MVC pipeline and are applied at controller or action level.

🔷 6. How to Create Custom Middleware?
Custom middleware is created by defining a class with a constructor accepting RequestDelegate and an Invoke method, and then registering it using UseMiddleware.

🔷 7. What is RequestDelegate?
RequestDelegate is a function that represents the next middleware in the pipeline and is used to pass the HTTP request to the next component.

🔹 Q1: What is ASP.NET Core Web API?
ASP.NET Core Web API is a framework used to build RESTful HTTP services that return data in JSON format. It is cross-platform, high-performance, and uses middleware-based architecture. In my project, I used it to connect Angular frontend with SQL Server using Dapper.

🔹 Q2: Explain Request Lifecycle
When a request comes, it first goes through middleware pipeline like routing, authentication, and authorization. Then it reaches the controller action method, processes business logic, fetches data from database, and returns response. The response then flows back through middleware in reverse order.

🔹 Q4: How Routing Works?
Routing maps incoming requests to specific controller actions. In Web API, we mainly use attribute routing like [HttpGet], [HttpPost], which gives better control over endpoints.
🔷 How Routing Works (Internally)
Request comes → /api/student/1
Routing middleware matches URL
Finds controller + action
Executes that method

🔷 What is Routing?
👉
Routing is the process of mapping an incoming HTTP request (URL) to a specific controller action method.

🔹 Q5: What is Dependency Injection?
👉
Dependency Injection is a design pattern used to achieve loose coupling by injecting dependencies into a class instead of creating them inside the class.
public class StudentController
{
    private StudentService _service = new StudentService(); // ❌ tightly coupled
}

public class StudentController
{
    private readonly IStudentService _service;

    public StudentController(IStudentService service)
    {
        _service = service; // ✅ injected
    }
}
